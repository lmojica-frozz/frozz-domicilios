# Frozz Domicilios

Sistema de domicilios de materiales de **Frozz Colombia S.A.S.**

- **`web/`** – Panel de despacho (se publica en GitHub Pages). Entra solo quien esté en la colección `admins` de Firestore, con su cuenta de Google.
- **`android/`** – App de los domiciliarios. Cada cambio en esta carpeta compila un APK nuevo y lo publica en *Releases*.
- **`firestore.rules`** – Reglas de seguridad de la base de datos (copia de las publicadas en Firebase).

Descarga del APK (siempre la última versión):
https://github.com/lmojica-frozz/frozz-domicilios/releases/latest/download/frozz-domiciliarios.apk

Proyecto de Firebase: `frozz-domicilios` (plan Spark).
